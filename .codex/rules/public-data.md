# Public Data Rules

- 공공 데이터는 공식 문서와 원출처를 우선한다.
- KOSIS/KOSTAT 값은 가구 단위 집계 통계다. 개별 페르소나의 실제 소득, 자산, 구매력으로 해석하지 않는다.
- 지표 단위는 그대로 보존한다. KRW가 아닌 값을 `원`으로 강제 변환하지 않는다.
- API 연결 순서는 무료, 공식, 안정성, 라이선스 명확성, 갱신 주기, 테스트 가능성을 기준으로 한다.
- 외부 데이터는 LLM 분석을 보정하는 보조 컨텍스트다. 실제 시장조사나 매출 예측으로 표현하지 않는다.
- 이미지 입력 옵션은 사용자가 켠 경우에만 API 호출한다. 기본 경로는 텍스트 입력만으로 진행 가능해야 한다.
